# Contribuir

Descrever o problema e reproduzir com dados fictícios. Usar Python 3.11+, sem dependências runtime novas por conveniência. Executar unittest e os três exemplos do README. Incluir limites, fórmulas e casos negativos no contrato quando o comportamento mudar.

Uma PR deve manter um objetivo coerente, testes e documentação da mudança juntos. Não adicionar crawler, credenciais, conector de escrita, publicação ou gasto no núcleo offline. Não alterar exemplos para conter export de cliente. Revisão humana antes de merge; CI verde não equivale a integração em produção.
